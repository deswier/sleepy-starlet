# Lullaby — Памятка по тестированию

---

## 1. Аутентификация

### Регистрация по email
- [ ] Форма: имя (обязательно), email (обязательно), пароль (мин. 6 символов), повтор пароля
- [ ] Обязательные поля отмечены красной звёздочкой `*`
- [ ] Пароль скрыт по умолчанию, кнопка с глазом показывает/скрывает
- [ ] Кнопка «Создать аккаунт» заблокирована, пока пароли не совпадают
- [ ] При несовпадении паролей — сообщение об ошибке под полем
- [ ] После отправки — экран «Проверьте почту» (не тост, а отдельный экран)
- [ ] После подтверждения по ссылке из письма — редирект в приложение
- [ ] Если email уже занят — понятная ошибка (не raw-ключ)

### Вход по email
- [ ] Неверный пароль → «Неверный email или пароль»
- [ ] Неподтверждённый email → «Сначала подтвердите ваш email»
- [ ] Слишком много попыток → «Слишком много попыток. Попробуйте позже»
- [ ] После успешного входа — редирект на последнюю страницу (или `/` → список детей)

### Вход через Google
- [ ] Кнопка «Войти через Google» открывает OAuth-поток
- [ ] После успешного входа — редирект в приложение
- [ ] Ошибка Google → тост «Не удалось войти через Google»

### Забытый пароль
- [ ] Кнопка «Забыли пароль?» на экране входа
- [ ] Вводишь email → экран «Ссылка отправлена»
- [ ] По ссылке из письма → форма «Новый пароль» + «Повторите пароль»
- [ ] После смены пароля — редирект на главный экран (не обратно на форму)
- [ ] Устаревшая / использованная ссылка → карточка «Срок действия ссылки истёк» с кнопками «Запросить новую» и «Вернуться ко входу»

### Выбор языка на экране авторизации
- [ ] Переключатель EN / RU в правом верхнем углу
- [ ] Все тексты на экране меняются сразу

## 2. Профиль пользователя

### Основные данные
- [ ] Отображается имя и email
- [ ] Изменение имени → сохраняется по кнопке «Сохранить»
- [ ] Изменение фото: кнопка «Изменить фото» → выбор файла → диалог обрезки → сохраняется
- [ ] После сохранения профиля — тост «Сохранено»

### Смена email
- [ ] Изменить email в поле → появляется подсказка и кнопка «Изменить email»
- [ ] Письмо подтверждения отправляется на новый email
- [ ] Тост «Письмо отправлено. Проверьте обе почты»

### Язык и формат времени
- [ ] Переключатель языка: Английский / Русский → весь интерфейс меняется сразу
- [ ] Переключатель формата времени: Системный / 12 часов / 24 часа
- [ ] При «Системный» — определяется по настройкам устройства / браузера
- [ ] Изменения вступают в силу сразу после «Сохранить»

### Смена пароля (пользователь с email/паролем)
- [ ] Три поля: «Текущий пароль», «Новый пароль», «Повторите пароль»
- [ ] Неверный текущий пароль → «Неверный текущий пароль»
- [ ] Несовпадение паролей → кнопка заблокирована + ошибка под полем
- [ ] Успех → тост «Пароль успешно изменён», поля очищаются
- [ ] Ссылка «Забыли пароль?» → отправляет письмо на текущий email, тост «Письмо для сброса отправлено»

### Установка пароля (Google-пользователь)
- [ ] Вместо формы смены — текст «Вход по паролю не настроен» + кнопка «Установить пароль через email»
- [ ] По кнопке — письмо для установки пароля отправляется на текущий email, тост «Письмо для сброса пароля отправлено»
- [ ] Форма ввода пароля **не** открывается прямо на странице — всё через поток восстановления
- [ ] По ссылке из письма — открывается стандартная форма «Новый пароль» / «Повторите»
- [ ] После установки через ссылку — при следующем открытии профиля отображается форма **смены** пароля (с полем текущего)

### Удаление профиля
- [ ] Кнопка «Удалить профиль» (красная)
- [ ] Сценарий **Заблокировано** — пользователь единственный владелец ребёнка с другими участниками → кнопка «Открыть настройки ребёнка», удаление невозможно
- [ ] Сценарий **Соло** — единственный участник → предупреждение, что ребёнок станет недоступен для восстановления
- [ ] Сценарий **Владелец с другими владельцами** — предупреждение, другие сохранят доступ
- [ ] Сценарий **Обычный** — просто подтверждение
- [ ] Кнопка «Удалить навсегда» + состояние «Удаляем…»
- [ ] После удаления — выход из аккаунта, редирект на `/auth`

## 3. Добавление ребёнка

### Новый ребёнок
- [ ] Поля: имя (обязательно), дата рождения, пол, кем приходитесь
- [ ] Дата рождения: нельзя выбрать дату в будущем (поле ограничено через `max`)
- [ ] При попытке сохранить будущую дату → «Дата рождения не может быть в будущем»
- [ ] Прошлые даты — без ограничений
- [ ] Пол: Мальчик / Девочка (необязательно)
- [ ] Отношение: Мама / Папа / Другое; при «Другое» — поле «Уточните роль»
- [ ] После создания — приветственный тост «Здравствуй, [имя]!» + редирект на главный экран

### Присоединение по коду
- [ ] Поле кода (6 символов, заглавные)
- [ ] Неверный код → «Неверный код»
- [ ] Слишком много попыток (счётчик привязан к аккаунту, смена устройства не сбрасывает) → «Слишком много попыток. Повторите через X»
- [ ] Успех → редирект на главный экран

## 4. Текущий сон

### Ребёнок не спит
- [ ] Карточка с солнцем и именем ребёнка
- [ ] Кнопка «Начать сон» (только Owner / Editor)
- [ ] Кнопка «Добавить вручную» (диалог с формой сна)

### Начало сна
- [ ] Нажать «Начать сон» → карточка переходит в ночной режим (тёмный фон)
- [ ] Время начала подписано под иконкой луны
- [ ] При пересечении с уже существующей записью → «Сон пересекается с уже существующей записью»
- [ ] Время начала можно редактировать: нажать на текст → поле ввода даты/времени → ✓ / ✗

### Во время сна
- [ ] Счётчик длительности обновляется каждые 30 секунд
- [ ] Кнопка «Проснулся» / «Проснулась» — текст с учётом пола ребёнка
- [ ] Кнопка «Добавить пробуждение» (если включена в настройках)
- [ ] Редактор (не начавший сон) видит кнопки «Проснулся» и «Добавить пробуждение» — может остановить чужой активный сон
- [ ] Редактор (не начавший сон) **не** видит карандаш редактирования времени начала и времени прерывания

### Прерывание сна
- [ ] Нажать «Добавить пробуждение» → состояние «⏸ Пробуждение с [время]»
- [ ] Время пробуждения можно редактировать карандашом
- [ ] Нажать «Завершить пробуждение» → открывается модал с началом / концом / способом укладывания
- [ ] Сохранить → сон продолжается, показывается счётчик прерываний

### Завершение сна
- [ ] Нажать «Проснулся(ась)» → открывается модал подтверждения (черновик — запись в БД ещё не создана)
- [ ] В модале: форма редактирования с уже заполненными временем начала / конца
- [ ] Подтвердить → запись в БД, возврат к экрану «не спит»
- [ ] Отмена → ничего не сохраняется, откат не нужен

## 5. История

- [ ] Переключение дней кнопками `<` `>` или датпикером
- [ ] Нельзя перейти в будущее (кнопка `>` заблокирована на сегодня)
- [ ] Список снов за день: иконка цвета (дневной / ночной), время начала, длительность
- [ ] Между снами — полоска «бодрствования» с длительностью и цветом нормы
- [ ] Текущий незавершённый сон отображается с меткой «активно»
- [ ] Внизу карточки: итог «Всего сна» + количество дневных снов
- [ ] Нажать на сон → детальная карточка
- [ ] Детали: дата, диапазон времени, длительность, тип, место, укладывание, прерывания, комментарий, «Добавил»
- [ ] Кнопки «Изменить» и «Удалить» — только при наличии прав
- [ ] Если создатель удалил аккаунт → «Удалённый пользователь»

### Формат времени в истории
- [ ] 24ч: `14:30`
- [ ] 12ч: `2:30 PM`
- [ ] Системный: по настройке устройства

### Формат длительности
- [ ] RU: `5ч15м`, `1ч05м`, `45м`, `0м`
- [ ] EN: `5h15m`, `1h05m`, `45m`, `0m`
- [ ] Нигде нет `HH:mm` для длительностей

## 6. Добавление / редактирование сна

- [ ] Поля: начало, конец (с датпикером), тип сна, место, укладывание (если включены), комментарий
- [ ] Конец не может быть раньше начала → ошибка
- [ ] Начало и конец не могут быть в будущем → ошибка
- [ ] Пересечение с другим сном → «Сон пересекается с уже существующей записью»
- [ ] Прерывания — список с добавлением / удалением; у каждого начало / конец / укладывание
- [ ] Прерывание вне границ сна → «Пробуждение должно быть в пределах сна»
- [ ] Пересечение прерываний → «Пробуждения не должны пересекаться»
- [ ] Успех → тост «Сон добавлен» / «Обновлено»

## 7. Аналитика

### Вкладка «День»
- [ ] Датпикер (не в будущее)
- [ ] Карточки: Всего сна, Всего бодрствования, Ночной сон, Среднее бодрствование (мин / макс), Дневные сны (среднее, мин, макс длительность)
- [ ] Рядом с нормой: ✓ если в норме, стрелки если выше / ниже
- [ ] Тултип по карточке: диапазон нормы + отклонение
- [ ] «Нет данных за этот день» — если нет снов

### Вкладка «Неделя»
- [ ] Выбор недели (не в будущее)
- [ ] Можно исключать отдельные дни из расчёта (нажать на день)
- [ ] Все метрики — средние за включённые дни
- [ ] «Текущий день не учитывается» — подсказка при текущей неделе
- [ ] Кнопка «Открыть диаграмму» → тепловая карта

---

## 8. Тепловая карта

- [ ] 7 колонок = 7 дней, вертикаль = время суток (0–24)
- [ ] Прямоугольники — периоды сна, иконки — прерывания
- [ ] Диаграмму можно листать перетаскиванием; нельзя уйти правее последнего дня с данными
- [ ] Диапазон дат в заголовке обновляется при прокрутке
- [ ] Нажать на прямоугольник сна → открывается карточка с деталями
- [ ] Нажать на иконку прерывания → открывается карточка соответствующего сна

### Редактирование и удаление из диаграммы
- [ ] Кнопки «Изменить» и «Удалить» видны только при наличии прав (Owner или Editor на свой сон)
- [ ] Удалить сон → подтверждение → прямоугольник исчезает с диаграммы **без перезагрузки страницы**
- [ ] Изменить сон → сохранить → диаграмма обновляется **без перезагрузки страницы**
- [ ] Наблюдатель открывает карточку, но кнопок «Изменить» / «Удалить» не видит

## 9. Настройки ребёнка

### Профиль ребёнка
- [ ] Фото: загрузка, обрезка, удаление (только Owner)
- [ ] Имя и дата рождения: редактирование сохраняется при потере фокуса (только Owner)
- [ ] Дата рождения не может быть в будущем → «Дата рождения не может быть в будущем»
- [ ] Показывается текущая норма бодрствования по возрасту

### Ночное окно
- [ ] Время начала и конца ночи (определяет тип сна и атрибуцию по дням)
- [ ] Поля и кнопка «Сохранить» доступны **Владельцу и Редактору**; у Наблюдателя экран упрощённый

### Отображение
- [ ] Переключатели: показывать место / укладывание / прерывания / разделять ночной сон по датам
- [ ] Чекбоксы и кнопка «Сохранить» **доступны только Владельцу**; у Редактора чекбоксы заблокированы и затемнены, кнопки «Сохранить» нет

### Места и способы укладывания
- [ ] Список с добавлением / удалением — доступны **Владельцу и Редактору**; Наблюдатель видит только список
- [ ] Удаление места / метода: запись **не исчезает из истории** — в карточке сна название по-прежнему отображается
- [ ] Удалённое место / метод **не появляется** в выпадающем списке при добавлении нового сна
- [ ] Названия по умолчанию переводятся по текущему языку (Кроватка / Crib и т.д.)

### Семейный доступ
- [ ] Кнопка «Сгенерировать код» → 6-значный код, действует 24 часа
- [ ] Кнопка «Копировать» → тост «Скопировано»
- [ ] Кнопка «Отозвать» — удаляет код (только для Владельца; Редактор и Наблюдатель кнопку не видят)
- [ ] Выбор роли для кода: Владелец / Редактор / Наблюдатель
- [ ] Список участников: имя, роль, кнопки «Изменить роль» / «Удалить участника» (только Owner)
- [ ] Параллельное редактирование настроек → тост «Настройки были изменены кем-то из семьи»

## 10. Права доступа

| Действие | Владелец | Редактор | Наблюдатель |
|---|---|---|---|
| Начать сон | ✓ | ✓ | ✗ |
| Остановить / завершить **любой** активный сон | ✓ | ✓ | ✗ |
| Редактировать **свой** сон¹ | ✓ | ✓ | ✗ |
| Редактировать **чужой** завершённый сон | ✓ | ✗ | ✗ |
| Ночное окно / места / способы укладывания | ✓ | ✓ | ✗ |
| Отображение (переключатели show_*) | ✓ | ✗ | ✗ |
| Управление участниками | ✓ | ✗ | ✗ |
| Удалить ребёнка | ✓ | ✗ | ✗ |

¹ «Свой» = сессия, которую пользователь **начал** (`created_by_user_id`) **или завершил** (`updated_by_user_id`). После того как Редактор останавливает чужой сон, он становится его «завершившим» и может затем редактировать эту запись.

- [ ] Наблюдатель не видит кнопок «Начать сон», «Проснулся», «Пробуждение»
- [ ] Редактор видит кнопки «Проснулся» и «Пробуждение» для чужого активного сна
- [ ] Редактор **не** видит карандаш редактирования времени начала и времени прерывания на чужом активном сне
- [ ] Редактор не может редактировать / удалять сон, который он не начинал и не завершал
- [ ] Редактор видит поля «Ночное окно» и кнопку «Сохранить»; видит кнопки добавления/удаления мест и методов
- [ ] Редактор **не** видит кнопку «Сохранить» в секции «Отображение»; чекбоксы заблокированы
- [ ] Через прямой API-запрос Наблюдатель получает ошибку 42501 при попытке записи в `child_settings`, `sleep_places`, `settling_methods`
- [ ] Через прямой API-запрос Редактор может обновить `child_settings` и `sleep_places` / `settling_methods` (ошибки нет)
- [ ] Через прямой API-запрос Наблюдатель получает ошибку 42501 при попытке записи в `sleep_interruptions`

### Защита последнего администратора
- [ ] Если пользователь — единственный Владелец, попытка понизить его роль через «Изменить роль» → ошибка сервера («Нельзя понизить или удалить последнего администратора»)
- [ ] Если пользователь — единственный Владелец, кнопка «Удалить участника» на нём самом не должна молча выполниться (UI её не отображает, на сервере заблокировано триггером)
- [ ] Владелец может понизить другого Владельца только при наличии хотя бы ещё одного Владельца

### Безопасность приглашений
- [ ] Коды приглашений **видит только Владелец** — Редактор и Наблюдатель не видят секцию с кодами
- [ ] Через прямой API-запрос Редактор и Наблюдатель получают пустой результат при SELECT на `child_invites`
- [ ] Отозвать и изменить роль кода может только Владелец; при попытке через другую роль → ошибка 42501
- [ ] Генерировать код может только Владелец

## 11. Удалённые дети

### Удаление из настроек (только Owner)
- [ ] Кнопка «Удалить ребёнка полностью» → диалог с предупреждением
- [ ] После удаления — ребёнок исчезает у всех участников, данные восстановимы 30 дней
- [ ] Кнопка «Удалить из моего аккаунта» — только сам пользователь теряет доступ, остальные сохраняют

### Страница «Удалённые дети» (Профиль → Удалённые дети)
- [ ] Список: имя, дата удаления, кто удалил, сколько дней осталось
- [ ] Кнопка «Восстановить» → ребёнок возвращается в список
- [ ] Если список пуст → «Нет удалённых детей»

---

## 12. Офлайн-режим

- [ ] Баннер «Нет сети» появляется при отключении интернета
- [ ] Добавление / изменение сна офлайн → сохраняется в очередь (IndexedDB)
- [ ] При восстановлении → баннер «X изменений ожидают синхронизации» → автосинхронизация
- [ ] При конфликте (тот же сон изменили на сервере) → переход на `/conflicts`
- [ ] На экране конфликтов: «Ваша версия» vs «Серверная версия», кнопки «Оставить мою» / «Оставить серверную»

## 13. Локализация

- [ ] Переключение RU → EN: все тексты меняются без перезагрузки страницы
- [ ] Нигде нет «сырых» ключей (`sleep.startedAt`, `common.save` и т.д.)
- [ ] Длительности RU: `5ч15м`, `1ч05м`, `0м`
- [ ] Длительности EN: `5h15m`, `1h05m`, `0m`
- [ ] «Проснулся» / «Проснулась» — зависит от пола ребёнка (RU)
- [ ] Места и методы по умолчанию: RU — «Кроватка», «Укачивание»; EN — «Crib», «Rocking»

## 15. Realtime (многопользовательский режим)

- [ ] Открыть приложение на двух устройствах под одним ребёнком
- [ ] Начать сон на устройстве 1 → устройство 2 обновляется автоматически
- [ ] Завершить сон на устройстве 2 → устройство 1 обновляется
- [ ] Добавить прерывание → CurrentSleep на обоих устройствах обновляется (канал на `sleep_session_id`)
- [ ] История не подписывается на изменения прерываний в реальном времени — длительность сна в списке не зависит от прерываний (`end − start`); актуальные прерывания видны при открытии карточки сна

## 16. Граничные случаи (обязательно проверить)

- [ ] Пароль менее 6 символов → «Слишком слабый пароль»
- [ ] Несовпадение паролей → кнопка заблокирована
- [ ] Начало сна в будущем → «Начало не может быть в будущем»
- [ ] Конец раньше начала → «Конец должен быть позже начала»
- [ ] Прерывание вне границ сна → «Пробуждение должно быть в пределах сна»
- [ ] Пересекающиеся прерывания → «Пробуждения не должны пересекаться»
- [ ] Дата рождения ребёнка в будущем → «Дата рождения не может быть в будущем»
- [ ] Создание сна при уже активном → «Сон пересекается с уже существующей записью»
- [ ] Повторное использование ссылки сброса пароля → экран «Срок действия ссылки истёк»
- [ ] Удаление профиля при наличии детей без второго владельца → «Невозможно удалить профиль»
- [ ] Ребёнок без даты рождения → норма бодрствования не показывается
- [ ] Понижение роли единственного Владельца с другими участниками → ошибка сервера
- [ ] Удаление единственного Владельца из семьи → ошибка сервера
